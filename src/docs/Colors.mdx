# Colors

Monochrome surfaces with one electric-lime accent. Product screenshots are meant
to be the only saturated colour on a page, so the UI itself stays quiet.

Depth comes from shifting surface values, not shadows.

> **Source of truth:** `src/tokens/tokens.css`. The swatches below are a copy for reading; if they ever disagree, the CSS wins.

## Why lime changes role

| Pairing | Contrast | Result |
| --- | --- | --- |
| lime-300 `#BEF264` text on dark `#0A0A0B` | 15.15 : 1 | AAA |
| lime-300 `#BEF264` text on light `#FBFBFA` | 1.26 : 1 | **Fails** |
| lime-700 `#4D7C0F` text on light | 4.82 : 1 | AA |
| `#131313` text on lime-300 surface | 14.22 : 1 | AAA |
